# 学考每日打卡（广东高中学考 · 高频考点100题）

一个纯静态的每日刷题打卡网页。题库来自四科 PDF，
**所有题目、选项、答案、解析均逐字取自原 PDF，未做任何编造或联网补全。**

> ⚠️ **本仓库不包含原始 PDF 题库**（`高频考点100题/`、`合格考必背知识点/` 已在 `.gitignore` 中排除）。
> 网页运行只需 `data/` 下的 JSON 与截图；若要重新解析，请自备原卷 PDF 放到 `高频考点100题/` 后运行 `tools/build_bank.py`。

## 目录结构

```
├── data/                   # 由 PDF 解析生成的数据（仓库内）
│   ├── questions.json      # 题库（400 题，网页读取这个文件）
│   ├── img/<科目>/<题号>.webp  # 每道题的原题截图（图片题/公式/表格靠它保真）
│   └── report.md           # 解析报告
├── web/                    # 网页（纯静态，无依赖、无构建）
│   ├── index.html
│   ├── style.css
│   └── app.js
├── tools/                  # 解析与校验脚本
│   ├── build_bank.py       # PDF → questions.json + 截图
│   └── verify_bank.py      # 题库一致性校验
└── README.md

# 以下不进仓库（本地自备）
# 高频考点100题/          # 原始题库 PDF（题目卷 + 答案卷，四科）
# 合格考必背知识点/        # 原始知识点 PDF（本工具未使用）
```

## 怎么用

### 本机打开

浏览器不允许 `file://` 读取 JSON，需要一个本地服务：

```bash
cd 20261116-广东高中学考备考
python -m http.server 8000
```

然后打开 <http://127.0.0.1:8000/web/>。

### 手机打卡（GitHub Pages）

推送后在仓库 `Settings → Pages` 把 Source 设为 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)`，
保存后访问：

```
https://<你的用户名>.github.io/xuekao-daily/web/
```

> 注意结尾要有 `/web/`。首页路径不是仓库根目录。

做题记录保存在**当前设备的浏览器**里（localStorage），换设备不会自动同步：

- 想换设备继续：在「设置 → 导出记录」导出 JSON，再到新设备「导入记录」。
- 清除浏览器数据会丢失记录，重要进度请定期导出。

### 更新后手机看不到新版？

`index.html` 里给 `style.css` / `app.js` 带了版本号（`?v=YYYYMMDD`）。
改动前端后，把这三处版本号一起 +1 再推送，手机刷新即可拿到新文件；否则会命中浏览器缓存。

## 功能

- **每日任务**：默认 10 道新题 + 5 道到期错题（数量可在设置里调）
- **判分与解析**：提交后立即标出对错，错题展示「你的答案 / 正确答案 / 原卷解析 / 原题截图」
- **错题本**：按科目筛选，可一键重练；记录每题错了几次、下次复习日期
- **间隔重复**：答对后下次复习间隔为 1 → 3 → 7 → 15 → 30 → 60 天；答错归零、次日重现
- **打卡日历**：当天做过题即记为打卡，显示连续打卡天数
- 手机 / 电脑自适应，图片可点击放大

## 数据可信度

解析脚本遵循两条硬规矩：

1. **不编造**：题干、选项、答案、解析全部来自 PDF 文本，脚本从不生成内容。
2. **宁缺毋滥**：对不上的地方写进告警，不猜、不填默认值。

原 PDF 里存在的排版问题（已在脚本中显式处理并注释）：

| 位置 | 原 PDF 问题 | 处理方式 |
|---|---|---|
| 生物 第78题 | 答案卷把题号印成「18．」 | 用题干文本与题目卷比对确认后纠正 |
| 地理 第20/23/44/54/74/80 题 | 题号与题干被拆成两个文本块 | 按坐标合并同一行 |
| 地理 `45..B`、`6.D` | OCR 把 `45.B`/`46.D` 拆坏 | 按连续题号补齐（需与题干一致） |
| 历史/政治 第58/71/89 题 | 选项 A 被塞进题干括号 `(A ).` | 提取为 A 选项 |
| 地理 第64题 | 选项 A/B/C/D 本身就是图片 | 选项留空，用原题截图作答 |

## 重新生成题库

改动 PDF 或想重跑解析：

```bash
cd tools
python build_bank.py        # 重新解析四科，生成 data/questions.json 和截图
python verify_bank.py       # 校验：题号连续、答案在选项内、截图齐全等
```

`build_bank.py` 只依赖 `PyMuPDF`（`fitz`）和 `Pillow`。

## 图片格式

题目截图统一使用 **WebP（有损 q80）**，而非 PNG：

| 格式 | 400 张总大小 |
|---|---|
| PNG（原始） | 25.70 MB |
| **WebP q80（当前）** | **10.56 MB**（省 59%） |

选 q80 而非更激进的 q70，是因为这些截图是复习时唯一的凭据：
实测把文字区域放大 2 倍对比，q80 与 PNG 肉眼无法分辨，文字与线条依旧锐利；
q70 只再省约 10%，但边缘开始出现轻微发虚，不值得。

改动格式只需调整 `build_bank.py` 里的 `IMG_FORMAT` / `IMG_QUALITY`。
